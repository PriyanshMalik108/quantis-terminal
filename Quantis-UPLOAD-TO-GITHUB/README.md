# Quantis Terminal

Live site: **https://priyanshmalik108.github.io/quantis-terminal/**

| Folder | What it is |
|---|---|
| repository root (`index.html`, `assets/`, `sw.js`, …) | the **built, minified website** served by GitHub Pages — do not edit by hand |
| `source/` | the readable source code, docs and tests — **edit here** |

Editing: change files in `source/`, commit and push. The *Build site* GitHub Action rebuilds the site and
updates the root files automatically (about 1 minute). See `source/README.md` and `source/docs/`.

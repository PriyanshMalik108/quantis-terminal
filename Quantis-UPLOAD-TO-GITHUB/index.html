Max Sharpe, Target Return, and Target Volatility are all long-only constrained (weights ≥ 0, sum to 100%) via projected-gradient optimization, not a full interior-point QP solver — for small holding counts (a handful of assets) this converges to the same long-only-constrained optimum.

Data Provider Settings

Cloud Sync — Sign in with Google NOT CONFIGURED

This app is a single HTML file with no server of its own, so there's no shared Quantis account database to sign into directly. What actually makes "sign in and save my data" work here is your own free Firebase project (Google's backend-as-a-service — the same free tier real production apps use, not a toy). It takes about 5 minutes, needs no credit card, and once connected below, "Sign in with Google" saves your watchlists, portfolio, alerts, screens, and notes to your own private cloud database, synced across every device you sign into.
  1. Go to console.firebase.google.com → Add project (free) → skip Google Analytics if asked.
  2. In your new project: Build → Authentication → Get started → Sign-in method → Google → Enable.
  3. Build → Firestore Database → Create database → start in test mode (fine for personal use; you can lock it down with security rules later).
  4. Project settings (gear icon) → General → scroll to "Your apps" → Add app → Web (</>) → register it → copy the firebaseConfig object shown.
  5. Paste that whole object below and click Connect.
What syncs: watchlists/workspaces, portfolio holdings, price alerts, saved screener criteria, position notes. What never syncs: your API keys (Finnhub, Trade.gov, AI keys above) — those stay in this browser's local storage only, on this device, never sent anywhere but the provider they're for.
Always-on, keyless, free: CNBC (live quotes, 10-year price history, news), TradingView (fundamentals, statements, analyst consensus, screener, logos), BLS and DBnomics (US macro), Frankfurter/ECB (FX), CoinGecko (crypto), World Bank, CFTC and AMFI data. No setup needed.

Optional — bring your own free key: unlock the extras below. Keys are stored only in this browser's localStorage and sent directly to the provider — never to Anthropic or any Quantis server.
Statement line items: with an FMP, Alpha Vantage or Finnhub key the Analysis tab, Formula Lab and reports use exact reported lines (interest, tax, receivables, inventory, payables, buybacks, stock-based pay) and quarterly cash flows. Preference order: FMP → Alpha Vantage → Finnhub. Need a different provider? Add it in Data Sources → Your own APIs.
Finnhub's free tier terms restrict redistribution/display in some contexts — verify finnhub.io/terms-of-service for your use case before relying on this in anything beyond personal/research use. This app only ever shows Finnhub's raw numbers with clear attribution, never re-sells or strips the source.
Powers the Screening view's sanctions-list search (OFAC SDN + 10 other US government consolidated lists, via the official Census/Commerce/State-run API at api.trade.gov). Get a free key at developer.trade.gov — instant, no card needed. Without a key, that search stays disabled rather than silently returning nothing.
Not needed for normal use. A personal proxy only adds sources that refuse browser requests — Yahoo Finance, SEC EDGAR filings (US income statements and Form 4 insider filings) and community sentiment. A free Cloudflare Worker takes about a minute to set up.
Even better — no proxy needed at all, for these specific sources: Indian mutual funds (AMFI) and ~50 major companies' real fundamentals (SEC EDGAR) can be mirrored straight into your own GitHub Pages repo by a free scheduled GitHub Action, so the app reads them from its own origin with zero CORS exposure — nothing to deploy on Cloudflare, nothing that can rate-limit or go down. Download each workflow file below, add it to your repo at the exact path shown, then run it once from the Actions tab.
Optional — AI Research Assistant upgrade: the assistant works with zero setup (grounded answers from real computed data only). Adding your own key routes questions to a real LLM instead, still constrained to only the same computed data as context. Verified: Anthropic's API genuinely supports direct browser calls via the documented anthropic-dangerous-direct-browser-access header — this isn't a workaround. Note on "free AI API": there is no such thing as a universal, keyless, free LLM API — every real provider (Anthropic, OpenAI, Groq, everyone) requires its own account so it can meter usage, even on a free tier. Groq below is the closest to that ask: no credit card, a generous free-tier quota, and fast open models — but it still needs a personal key, taking about 30 seconds to create at console.groq.com.

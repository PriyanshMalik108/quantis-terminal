These are hypothetical allocations computed from the same historical return series as the risk metrics above — clicking one does not change your actual holdings. Max Sharpe, Target Return, and Target Volatility are all long-only constrained (weights ≥ 0, sum to 100%) via projected-gradient optimization, not a full interior-point QP solver — for small holding counts (a handful of assets) this converges to the same long-only-constrained optimum.

Rebalancing Suggestions REAL — computed from current $ weights

Trade suggestions to move your CURRENT holdings toward whichever allocation is selected above (defaults to Equal Weight). Purely a distance calculation between today's $ weights and the target — not a recommendation on which target to pick, and doesn't account for trading costs, taxes, or minimum lot sizes.

Tax-Loss Harvesting REAL — computed from your avg cost vs current price

Positions currently below your average cost, sorted by largest unrealized loss. Not tax advice — the U.S. wash-sale rule (and equivalents elsewhere) can disallow the loss if you rebuy the same or a "substantially identical" security within 30 days; consult a tax professional before acting on this.

Data Provider Settings

Always-on, keyless, free: Yahoo Finance chart API (equity historical prices, all exchanges), Frankfurter/ECB (FX), CoinGecko (crypto). No setup needed.

Optional — bring your own free key: unlock deeper fundamentals/quotes. Keys are stored only in this browser's localStorage and sent directly to the provider — never to Anthropic or any Quantis server.
FRED's public API does not reliably support direct browser (CORS) requests, so macro data may still show as sample even with a key set, until a proxy is added.
Equity data (Yahoo Finance) isn't reachable directly from a browser — no CORS headers. Without a proxy here, Quantis tries several public fallback proxies in turn (corsproxy.io, allorigins.win, codetabs.com), which are free but unreliable/rate-limited and run by third parties — don't rely on them for anything serious. They're also known to reject requests from a page opened straight from a phone's Downloads/Files app (a "null" origin, since it isn't served over http/https) — if you're seeing every single provider fail, that's the likely reason, and no proxy fixes it: open this file through a real http(s) URL instead (e.g. host it, or open it via the address the AI gave you rather than a downloaded copy). For real reliability, deploy the tiny proxy worker below (free, ~60 seconds, no account beyond a free Cloudflare account) and paste its URL above.
Even better — no proxy needed at all, for these specific sources: Indian mutual funds (AMFI) and ~50 major companies' real fundamentals (SEC EDGAR) can be mirrored straight into your own GitHub Pages repo by a free scheduled GitHub Action, so the app reads them from its own origin with zero CORS exposure — nothing to deploy on Cloudflare, nothing that can rate-limit or go down. Download each workflow file below, add it to your repo at the exact path shown, then run it once from the Actions tab.
Optional — AI Research Assistant upgrade: the assistant works with zero setup (grounded answers from real computed data only). Adding your own key routes questions to a real LLM instead, still constrained to only the same computed data as context. Verified: Anthropic's API genuinely supports direct browser calls via the documented anthropic-dangerous-direct-browser-access header — this isn't a workaround. Note on "free AI API": there is no such thing as a universal, keyless, free LLM API — every real provider (Anthropic, OpenAI, Groq, everyone) requires its own account so it can meter usage, even on a free tier. Groq below is the closest to that ask: no credit card, a generous free-tier quota, and fast open models — but it still needs a personal key, taking about 30 seconds to create at console.groq.com.
Live Macro Dashboard: the FRED key above (fred.stlouisfed.org, free, instant signup) also powers the Macro Dashboard's real US Treasury yields/CPI/GDP/unemployment — no separate signup needed. VIX/Gold/Brent/DXY on the same tab don't need this — they're already live via Yahoo Finance.

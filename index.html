Data Provider Settings

Always-on, keyless, free: Stooq (US equity historical prices), Frankfurter/ECB (FX), CoinGecko (crypto). No setup needed.

Optional — bring your own free key: unlock deeper fundamentals/quotes. Keys are stored only in this browser's localStorage and sent directly to the provider — never to Anthropic or any Quantis server.
FRED's public API does not reliably support direct browser (CORS) requests, so macro data may still show as sample even with a key set, until a proxy is added.
Equity data (Stooq, Yahoo Finance) isn't reachable directly from a browser — no CORS headers. Without a proxy here, Quantis tries several public fallback proxies in turn (corsproxy.io, allorigins.win, codetabs.com), which are free but unreliable/rate-limited and run by third parties — don't rely on them for anything serious. They're also known to reject requests from a page opened straight from a phone's Downloads/Files app (a "null" origin, since it isn't served over http/https) — if you're seeing every single provider fail, that's the likely reason, and no proxy fixes it: open this file through a real http(s) URL instead (e.g. host it, or open it via the address the AI gave you rather than a downloaded copy). For real reliability, deploy the tiny proxy worker below (free, ~60 seconds, no account beyond a free Cloudflare account) and paste its URL above.
Optional — AI Research Assistant upgrade: the assistant works with zero setup (grounded answers from real computed data only). Adding your own key routes questions to a real LLM instead, still constrained to only the same computed data as context. Verified: Anthropic's API genuinely supports direct browser calls via the documented anthropic-dangerous-direct-browser-access header — this isn't a workaround. Note on "free AI API": there is no such thing as a universal, keyless, free LLM API — every real provider (Anthropic, OpenAI, Groq, everyone) requires its own account so it can meter usage, even on a free tier. Groq below is the closest to that ask: no credit card, a generous free-tier quota, and fast open models — but it still needs a personal key, taking about 30 seconds to create at console.groq.com.
